# ストア用スクリーンショットの撮り方（Showglobe Japan）

Google Play のスクリーンショットは「アプリの UI だけを見せる」「実際の機能と一致させる」
決まりです（`yourwish/docs/aso-rules.md` 5-2）。このため、**画面は実機（またはエミュレータ）で撮った
そのままの画像**を使い、このリポジトリのツールが背景と見出しを足します。

## 手順
1. 端末の言語（またはアプリ内の言語）を切り替え、下の 8 画面を撮る
   （縦向き、できれば 1080×2340 前後。ステータスバーの時刻は 9:41 など、通知は消しておく）。
2. `store/screenshots/raw/<言語コード>/<番号>_<名前>.png` に置く。例: `raw/ja/01_home.png`
   言語コードは `ja en zh zh-TW ko es fr pt id vi th hi ar`。最初は `ja` と `en` だけでも構いません。
3. 次を実行（Chrome/Chromium と Pillow が必要。コアのツール `compose_store_screenshots.py` を使う）:

```
python3 <コアのパス>/tools/compose_store_screenshots.py \
  --raw store/screenshots/raw --captions store/screenshots/captions.json \
  --out store/screenshots/out --brand-color "#E63946" --series "Showglobe Japan" --lang ja,en
```

4. `store/screenshots/out/<言語>/` の画像を Play Console / App Store Connect に上げる。
   `_sheet.png` は並びの確認用（アップロードしない）。

## 8 画面（この順に並べる。1 枚目は「何ができるか」の約束）
| 番号と名前 | 撮る画面 | 見せたいこと |
|---|---|---|
| `01_home` | ホーム（ヘッダー、クイックメニュー、スポット一覧が見える状態） | 旅の入口がひとつにまとまっている |
| `02_lens` | AI レンズの結果（有名な場所の写真で、説明とフレーズが出ている） | 撮るだけで解説 |
| `03_menu` | メニュー翻訳の結果 | 食事で困らない |
| `04_favorites` | お気に入り一覧（カテゴリのチップが 2 つ以上出ている） | 行きたい場所を保存 |
| `05_plan` | プラン詳細（「1日目」「2日目」が付いた状態。お気に入りから作る） | 日ごとの旅程になる |
| `06_stamps` | スタンプ帳（タイルマップが色づき、スタンプが並ぶ） | 都道府県を集める |
| `07_card` | しおりカードの共有プレビュー（季節フレームを選んだ状態） | カードで共有できる |
| `08_phrases` | フレーズ集 | 現地で使える言葉 |

## 撮るときの注意
- **実在しない機能や、アプリに無い画面は載せない。** 撮れない画面があれば、その番号は飛ばしてよい
  （4 枚以上あればよい）。
- 個人情報（メールアドレス、顔写真、実名）は映さない。テスト用アカウントで撮る。
- 見出しに「今すぐダウンロード」などの行動喚起を足さない（`captions.json` には入れていません）。
- 画面を加工しない（合成、差し替え、文字の書き足しをしない）。
- 見出しは A/B テストで効果を確かめてから確定する（スクショへの文言追加は効かないこともある）。
- 見出しの母語話者の確認は未了。公開前に確認してください。
