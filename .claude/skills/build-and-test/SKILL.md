# build-and-test スキル

改修セッション時にビルド完了後、自動的にエミュレータテストを実行するスキル。

## 用途

```bash
/build-and-test japan_explorer
```

## テスト観点

1. **起動テスト** ✅
   - アプリが正常に起動できるか
   - クラッシュなく初期画面が表示されるか

2. **各連携テスト** ✅
   - バックエンド API への接続
   - Firebase / Analytics との連携

3. **購入画面テスト** ✅
   - Google Play Billing の UI が正常に表示されるか
   - 購入フローの初期段階が動作するか

4. **認証テスト** ✅
   - ログイン画面が表示されるか
   - 認証フローが開始できるか
   - トークン取得エラーがないか

5. **広告テスト** ✅
   - Google Mobile Ads SDK が初期化されるか
   - 広告フォーマット（バナー、インタースティシャル、リワード）が読み込めるか
   - 広告関連のエラーログがないか

## テスト結果の見方

### ✅ 合格
- すべてのテスト観点が確認された
- エラーログが最小限（警告は許容）

### ⚠️ 要確認
- 一部の連携でエラーが検出された
- ネットワーク接続を確認してから再テスト

### ❌ 失敗
- アプリのクラッシュ
- 基本的な起動失敗
- 複数の連携エラー

## 前提条件

- Android SDK がインストール済み
- エミュレータまたは物理デバイスが接続可能
- adb コマンドが利用可能
